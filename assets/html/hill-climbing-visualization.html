📚 Algorithm Overview

What is Hill Climbing Search?

Hill climbing is a local search algorithm that iteratively improves a solution by making small modifications. Starting from an initial state, it explores neighbors and moves to the one with the best score, repeating until no improvement is found.

Application: Predicate Discovery

In this case, we're searching for the best set of predicates (logical conditions) that can describe a planning domain. The algorithm starts with an empty set and iteratively adds predicates that most improve the quality of learned planning operators.

Goal: Minimize the heuristic score (lower is better) by finding predicates that lead to efficient task planning.

function HillClimbing(initial_state):
    current_state = initial_state
    current_score = evaluate(current_state)
    
    while True:
        // Generate all neighbors (add one predicate)
        neighbors = generate_neighbors(current_state)
        
        // Evaluate each neighbor
        best_neighbor = None
        best_score = current_score
        for neighbor in neighbors:
            score = evaluate(neighbor)
            if score < best_score: // Lower is better
                best_neighbor = neighbor
                best_score = score
        
        // If no improvement found, terminate
        if best_neighbor is None:
            break
        
        // Move to best neighbor
        current_state = best_neighbor
        current_score = best_score
    
    return current_state

💡 Key Insights

Why Hill Climbing Works Here

  • Greedy but Effective: Each step makes the locally optimal choice
  • Huge Improvement at Start: First predicate reduced heuristic by 99.7%
  • Diminishing Returns: Later steps show smaller improvements
  • Fast Convergence: Only 5 steps needed from 121 candidates

Limitations

  • Local Optima: May get stuck if initial state is poorly chosen
  • No Backtracking: Cannot undo previous decisions
  • Order Dependent: Different starting points may yield different results
